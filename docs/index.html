Finance & Revenue

Detailed money report — wallet liability, collections, GST and a profit estimator.

How the numbers are built: "Revenue" = recharge tickets marked completed in the Recharge Requests tab (i.e. payment actually collected by your team). The ₹5,000 / ₹500 admin test-account balance is excluded from revenue automatically. GST rate and operating costs / payouts below are editable — nothing here is invented, but profit needs your real cost numbers to be accurate, so it starts at ₹0 until you fill them in.

Announcements

Type a message and send it — it pops up for every signed-in user, on both the phone app and the web app, the moment it's sent (or the next time they open the app if it was closed).

Note: this reaches users while the app is open (a live connection), same as how incoming calls arrive — it is not an OS push notification for a fully closed app. If someone had the app closed, they'll see it as soon as they next open it.
